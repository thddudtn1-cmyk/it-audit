# IT 자체감사 관리 시스템

기획서는 `docs/PRD.md`, 작업 규칙은 `CLAUDE.md`를 참고한다.

## 빌드·실행

JDK 17과 Maven이 필요하다.

```bash
mvn package                                    # 빌드 + 테스트
java -jar target/it-audit-0.1.0-SNAPSHOT.jar   # http://localhost:8080
```

- DB(H2 파일)는 실행 위치의 `data/db/`, 증적 파일은 `data/files/` 아래에 생성된다. 위치를 바꾸려면 `--app.data-dir=/경로`를 쓴다.
- 최초 기동 시 관리자 계정이 없으면 `admin` / `admin1234!`로 만든다. 첫 로그인 때 비밀번호 변경이 강제된다.
  초기 비밀번호는 환경변수 `APP_INIT_ADMIN_PASSWORD`로 바꿀 수 있다.
- **시연용 역할 선택 로그인**이 기본으로 켜져 있다. 로그인 화면에서 역할을 고르면 데모 계정(`demo-*`)으로 바로 들어간다.
  사내 도입·운영 시에는 `--app.demo-login.enabled=false`로 끈다 (끄면 데모 계정도 만들지 않고 `/demo-login`은 404).

## Render 배포 (시연용 호스팅)

저장소 루트의 `render.yaml`(Blueprint)과 `Dockerfile`로 배포한다. Render 는 Java 를 기본 제공하지 않아 Docker 이미지를 쓴다.
온프레미스 운영(실행 JAR + systemd)과는 별개이며, 같은 JAR 을 컨테이너로 감싼 것이다.

1. Render 대시보드 → **New → Blueprint** → 이 GitHub 저장소 선택 → `render.yaml` 적용
2. 배포가 끝나면 서비스 **Environment** 에서 `APP_INIT_ADMIN_PASSWORD`(자동 생성) 값을 확인해 `admin` 으로 로그인하고, 첫 로그인 때 비밀번호를 바꾼다.
3. 관리 화면에서 사용자·담당팀을 등록한다.

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 8080 | Render 가 지정 |
| `APP_DATA_DIR` | `./data` (Render: `/var/data`) | DB(`db/`)와 증적 파일(`files/`) 위치. **영구 디스크**를 마운트한다 |
| `APP_INIT_ADMIN_PASSWORD` | `admin1234!` | 최초 관리자 비밀번호 (Render: 자동 생성) |
| `DEMO_LOGIN_ENABLED` | `true` | 역할 선택 데모 로그인. Render 시연 서버에서도 켜 둔다. 실제 데이터를 넣거나 운영할 때는 `false` |
| `COOKIE_SECURE` | `false` (Render: `true`) | 세션 쿠키를 HTTPS 로만 전송 |

주의
- H2 파일 DB 라서 **영구 디스크가 필요**하고, 디스크는 유료 플랜에서만 붙는다. 무료 플랜에서는 재배포·유휴 종료 때 DB 와 첨부파일이 사라진다.
- 영구 디스크를 쓰면 인스턴스를 1개로 고정해야 한다 (DB 파일을 여러 인스턴스가 같이 쓸 수 없다).
- 데모 로그인이 켜져 있으면 URL 을 아는 누구나 관리자 역할로 들어갈 수 있다. 시연 데이터만 두고, 실제 데이터를 넣기 전에는 끈다.
